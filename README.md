# SPARC-Evac

Project page for SPARC-Evac, doctoral research by Mary Salami (UC Santa Barbara) on whether LLM evacuation agents respond to the right wildfire cues.

**Live site:** https://salami-mary.github.io/sparc-evac/

**Status:** research in progress. The site describes the study design; it does not report experimental results. The hero map is a schematic, and the interactive demo runs a small toy rule in JavaScript, not an LLM.

The site is a single static `index.html` with no build step.
